┌───────────────────────────────────────────────────────────────────────────┐
│ 🎯 WHAT IT DOES                                                           │
└───────────────────────────────────────────────────────────────────────────┘

   Tracks objects (people, vehicles, etc.) in the video.
   
   When an object shows for 2-3 seconds:
   ├─ Highlights it with a RED BOX
   ├─ Shows elapsed time
   └─ Automatically downloads screenshot

┌───────────────────────────────────────────────────────────────────────────┐
│ ⚡ QUICK START (3 STEPS)                                                  │
└───────────────────────────────────────────────────────────────────────────┘

   1. Open detection.html
   2. Load a video (upload or demo)
   3. Click ZONE button → System starts tracking!

   Wait 2.5 seconds with an object in frame → RED BOX + DOWNLOAD!

        └─ Box disappears

┌───────────────────────────────────────────────────────────────────────────┐
│ 🔐 HOW IT WORKS INTERNALLY                                                │
└───────────────────────────────────────────────────────────────────────────┘

   Frame Analysis Loop:
   
   For each video frame:
   ├─ Get all detected objects
   ├─ For each object:
   │  ├─ Check if already tracking
   │  ├─ If not → Create tracking entry
   │  ├─ Check elapsed time since first seen
   │  ├─ If time < 2.5s → Normal box
   │  ├─ If time >= 2.5s:
   │  │  ├─ Draw RED box
   │  │  ├─ Show time label
   │  │  └─ Download screenshot (once)
   │  └─ Update last seen time
   └─ Remove objects that left frame
